# Security

This project is unaudited and is a NEAR testnet demo only. It is not for real funds. It is provided as-is.

Please report vulnerabilities privately through GitHub private vulnerability reporting:

1. Open this repository's **Security** tab.
2. Choose **Report a vulnerability**.

Do not file a public issue for a security report, and do not send reports to a personal email address.

**Scope:** testnet only, unaudited software, provided as-is. Reports that depend on mainnet funds, production keys, or paid services are out of scope.
